How it works. Input is parsed and classified (derivative, integral, equation, limit, sum, matrix, or expression). Calculations are done by real engines — math.js for numerics and matrices, Nerdamer for symbolic calculus and equation solving — not guessed. The step breakdown is generated from the problem’s structure and verified numerically where possible; for integrals and hard symbolic problems the listed method is a hint, not a transcript of the engine’s internal path. Closed forms that these engines can’t find are reported honestly, with a numeric answer when one exists. For research‑level symbolic math, number theory or proofs, plug a Python + SymPy backend (or an LLM API) into solveProblem(). Image/handwriting input isn’t included in this build.
